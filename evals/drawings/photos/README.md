# Photos for the drawing-likeness eval

The photos themselves are not committed: most are shop product shots (The Block, Revolve, SSENSE, COS) or
Cat's own wardrobe photos, which don't belong in a public repo. They live in the project Library at
`/mnt/project-files/drawing-check/photos/`. Copy them into this folder to run `node scripts/eval-drawings.mjs`
with side-by-sides; without them the script still screenshots every case.

The ten skirt photos are the ones already in `evals/photo/photos` (CC-licensed), referenced from there.
