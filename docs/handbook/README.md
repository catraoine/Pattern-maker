# Maison Tracé company handbook

The short, current version of how Maison Tracé runs: one page per area. It exists because project
memory outgrew its size limit and decisions started living only deep inside long threads.

**Every department reads the page for its area before starting work, and updates it in the same PR
(or the same day) when a decision changes.** Keep pages short: state what is true now, with the date
it was decided. Put history in the decisions log, not in the area pages.

Last full rebuild: Oct 30, 2026, from project memory, the department threads and the open PR queue.

## Rules for this handbook

- **This repo is public.** No home address, bank details, tester names or contact details, tester
  codes, API keys or personal money figures here. Point to the private Claude Doc instead.
- Latest dated decision wins. When you change a rule, change it here and add one line to the
  decisions log.
- Long working detail stays in the Claude Docs linked from the business plan (Cat's hub). Every new
  doc is linked from the business plan.
- Code facts belong in [HOW-IT-FITS-TOGETHER.md](../HOW-IT-FITS-TOGETHER.md); the freeze list belongs
  in [SHIP-LIST.md](../SHIP-LIST.md). This handbook points to them rather than copying them.
